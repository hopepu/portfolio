# 개인 포트폴리오 웹사이트

Next.js와 React로 만든 개인 포트폴리오 사이트입니다.

## 구성
| 페이지 | 내용 |
|---|---|
| Title | 이름, 사진, 연락처 |
| About | 자기소개 |
| Skill | 사용 가능한 기술 스택 |
| Project | 프로젝트 카드 (클릭하면 상세 모달) |
| Career | 경력 |
| Education | 교육 이수 |

## 프로젝트 목록
| 프로젝트 | 기술 | 저장소 |
|---|---|---|
| SAP BTP 사내 통합 포털 (실무) | SAPUI5, SAP CAP, HANA Cloud, Cloud Foundry, AI 에이전트 | [sap-btp-portfolio](https://github.com/hopepu/sap-btp-portfolio) |
| IT 회사 프로젝트 관리 ERP | Spring Boot, React, MariaDB | [ProjectIT](https://github.com/hopepu/ProjectIT) |
| 식당 예약 서비스 (HappyTable) | Spring, Oracle, JSP | [RestaurantReservation](https://github.com/hopepu/RestaurantReservation) |
| 영화 검색 · 리뷰 사이트 | JSP, Servlet, Oracle | [Movie_Search_website-Spring_framework](https://github.com/hopepu/Movie_Search_website-Spring_framework) |

## 기술
Next.js (App Router), React, TypeScript, Tailwind CSS

## 실행
```bash
npm install
npm run dev
```
